# Uso del panel maestro Radar V1

1. Abrir `abrir_gui_orquestador_Radar_V1.py`.
2. Elegir perfil histórico o semanal y fuentes.
3. Elegir etapas: Corpus existente, Todas disponibles o selección individual.
4. Pulsar Simular y comprobar para revisar el plan sin descargas.
5. Pulsar Ejecutar seleccionadas; seguir cada estado y la terminal en vivo.
6. Detener cuando sea necesario; Preparar reinicio desde la etapa elegida permite continuar sin repetir lo anterior.
7. Pruebas del panel y pipeline ejecuta la suite local. Actualizar documentación renueva el estado documental.

Las etapas futuras aparecen como pendientes y no ejecutables. Abrir el panel no inicia una extracción automáticamente. El perfil histórico no implica reincorporar registros de Facebook; la reproducción de CSV histórico es una operación explícita.

La opción de renovar TXT/análisis guarda un respaldo antes de reemplazar salidas y las restaura si falla la operación. No modifican la división 56/14/13 ni autorizan abrir verificación para seleccionar columnas.
