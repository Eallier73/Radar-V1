# Extractores vigentes

Todos los programas de esta carpeta tienen uso en el flujo actual:

| Programa | Propósito |
| --- | --- |
| `1_extractors_youtube_Radar_V1.py` | Extraer comentarios de YouTube a CSV. |
| `2_extractors_twitter_Radar_V1.py` | Extraer publicaciones y respuestas de Twitter/X a CSV. |
| `3_extractors_medios_Radar_V1.py` | Extraer noticias a CSV con el contrato vigente de Medios. |
| `4_extractors_facebook_posts_Radar_V1.py` | Extraer publicaciones de Facebook. |
| `5_extractors_facebook_comentarios_Radar_V1.py` | Extraer comentarios y consolidar el CSV de Facebook. |
| `run_extraccion_Radar_V1.py` | Coordinar extracción, procesamiento, promoción a TXT y validación semanal. |

No se retira ninguno de ellos. Los contratos compartidos viven en
`scr_Radar_V1/compartido_Radar_V1/`; los procesadores, en `scr_Radar_V1/preprocesamiento_Radar_V1/`.
