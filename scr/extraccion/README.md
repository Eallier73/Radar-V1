# Extractores vigentes

Todos los programas de esta carpeta tienen uso en el flujo actual:

| Programa | Propósito |
| --- | --- |
| `1_extractors_youtube.py` | Extraer comentarios de YouTube a CSV. |
| `2_extractors_twitter.py` | Extraer publicaciones y respuestas de Twitter/X a CSV. |
| `3_extractors_medios.py` | Extraer noticias a CSV con el contrato vigente de Medios. |
| `4_extractors_facebook_posts.py` | Extraer publicaciones de Facebook. |
| `5_extractors_facebook_comentarios.py` | Extraer comentarios y consolidar el CSV de Facebook. |
| `run_extraccion.py` | Coordinar extracción, procesamiento, promoción a TXT y validación semanal. |

No se retira ninguno de ellos. Los contratos compartidos viven en
`scr/compartido/`; los procesadores, en `scr/preprocesamiento/`.
